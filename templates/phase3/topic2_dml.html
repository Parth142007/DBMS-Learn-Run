2. DML — Data Manipulation Language

Learn how to populate, modify, and delete tuples inside existing relational tables using INSERT, UPDATE, and DELETE, alongside transactional safety and unfiltered-change warnings.

2.1

What is DML and How Does it Operate?

Data Manipulation Language (DML) consists of SQL statements that manipulate the data values (records or tuples) stored inside existing tables.

DDL (Topic 1)
Structure / Container

Creates, alters, or drops table columns, keys, and definitions. Triggers implicit commits.

DML (Topic 2)
Data / Contents

Inserts, updates, or deletes rows within the existing columns. Governed by storage engine transaction rules.

Transaction Behavior & Autocommit: In MySQL, by default autocommit = 1, which means every standalone DML command is committed immediately upon execution. When running inside an explicit transaction block (START TRANSACTION; ... COMMIT;), InnoDB allows DML operations to be rolled back with ROLLBACK; if an error occurs.
2.2

The INSERT Statement

The INSERT INTO statement adds new tuples to a table. You can insert a single record or multiple records in a single statement.

1. Single-Row Insert (with column list)

Best practice: Explicitly naming columns protects code if table schema changes later.

INSERT INTO practice_students 
(roll_no, first_name, last_name, dept_code, gpa, city)
VALUES 
('P106', 'Sonia', 'Nair', 'CIVIL', 8.20, 'Kochi');
2. Multi-Row Bulk Insert

Significantly faster than separate inserts because it commits in a single network round-trip.

INSERT INTO practice_students 
(roll_no, first_name, last_name, dept_code, gpa)
VALUES 
('P107', 'Aditya', 'Joshi', 'CSE', 7.85),
('P108', 'Kavya', 'Menon', 'ECE', 9.30);
2.3

The UPDATE Statement & The WHERE Clause Hazard

The UPDATE statement modifies values in one or more existing rows.

THE NUMBER ONE DML DISASTER: OMITTING THE WHERE CLAUSE! If you write UPDATE practice_students SET gpa = 10.00; without a WHERE condition, every single student in the entire table will have their GPA set to 10.00! Always specify a filter (e.g. WHERE roll_no = 'P101') unless you explicitly intend to modify the entire dataset.
Safe Filtered Update Example: 
UPDATE practice_students 
SET gpa = 8.95, city = 'Mysuru' 
WHERE roll_no = 'P101';
2.4

The DELETE Statement

The DELETE FROM statement removes specified rows from a table. Just like UPDATE, omitting the WHERE clause will permanently delete all records!

Safe Filtered Delete Example: 
DELETE FROM practice_students 
WHERE roll_no = 'P105';
