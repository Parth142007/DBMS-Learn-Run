3. DQL — Data Query Language & SELECT Clauses

Master the fundamental retrieval engine of SQL: column projections, aliases, complex filtering with WHERE, logical operators, sorting, pattern matching with LIKE, and the logical query processing order.

3.1

The Logical Query Processing Order

One of the most important secrets of SQL is that the database engine does NOT execute clauses in the order you write them!

Logical Execution Pipeline:
1. FROM → 2. WHERE → 3. GROUP BY → 4. HAVING → 5. SELECT → 6. DISTINCT → 7. ORDER BY → 8. LIMIT
Why You Cannot Use Column Aliases in the WHERE Clause: Because the WHERE clause (Step 2) is evaluated before the SELECT list (Step 5) is projected, the database engine does not yet recognize any alias you define in SELECT col AS my_alias!
3.2

Core SELECT Clauses & Operators

Projection & Expressions: Select specific columns and compute calculated values. 
SELECT roll_no, 
       CONCAT(first_name, ' ', last_name) AS full_name, 
       gpa, 
       (gpa * 10) AS percentage 
FROM students 
ORDER BY gpa DESC 
LIMIT 5;
Filtering with WHERE, AND, OR, NOT: Filter records by multiple criteria. Remember AND has higher precedence than OR! 
SELECT roll_no, first_name, dept_id, gpa, semester 
FROM students 
WHERE (dept_id = 1 OR dept_id = 2) 
  AND gpa >= 8.50;
Range & Membership: BETWEEN and IN: BETWEEN is inclusive of both lower and upper bounds. 
SELECT event_title, event_type, capacity 
FROM events 
WHERE capacity BETWEEN 45 AND 100 
  AND event_type IN ('Workshop', 'Seminar');
Pattern Matching with LIKE & Wildcards: % matches 0 or more characters; _ matches exactly one character. 
SELECT roll_no, first_name, email 
FROM students 
WHERE roll_no LIKE '%CS%' 
  AND first_name LIKE 'A%';
NULL Checking: IS NULL vs. = NULL: In 3-valued logic, = NULL always returns UNKNOWN (false). You MUST use IS NULL! 
SELECT student_id, roll_no, first_name, mentor_id 
FROM students 
WHERE mentor_id IS NULL; -- Correct! (Students without a mentor)

Interactive Practice
Exercise 3.1: Top Performing Students in Department 1
Beginner

Query the students table to find the top 2 students in department 1 ordered by gpa descending.

Hint: Use WHERE dept_id = 1 ORDER BY gpa DESC LIMIT 2;.
Exercise 3.2: Upcoming Events by Date Range
Intermediate

Find all events scheduled in November 2026 (between '2026-11-01' and '2026-11-30') with capacity greater than 40.

Hint: Use WHERE event_date BETWEEN '2026-11-01' AND '2026-11-30' AND capacity > 40.
