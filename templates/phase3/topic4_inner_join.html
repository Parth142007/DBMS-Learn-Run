4. INNER JOIN — Combining Matching Records

Understand how relational databases link tables based on matching values in common key columns, filtering out unmatched records through the ON join predicate.

4.1

What is an INNER JOIN and How Does it Work?

An INNER JOIN returns only the rows where there is an exact match between the joined columns in both tables. If a row in Table A does not find a matching value in Table B, that row is excluded from the final result set.

Diagram 4.1: INNER JOIN Set Intersection

Figure 4.1: Only rows with matching keys (green intersection) are preserved. Unmatched rows on either side are discarded.

Syntax Structure
SELECT a.col1, b.col2 
FROM table_a a
INNER JOIN table_b b
  ON a.common_key = b.common_key;
ON vs. WHERE

The ON clause specifies the join condition (how tables link together). The WHERE clause specifies row filters applied to the joined result set. Keeping them separate makes queries clean and readable.

4.2

Live Executable Example & Schema Walkthrough

Let's join our real university tables students and departments using dept_id:

Executable INNER JOIN Query: 
SELECT s.roll_no, 
       CONCAT(s.first_name, ' ', s.last_name) AS student_name, 
       d.dept_code, 
       d.dept_name, 
       s.gpa 
FROM students s 
INNER JOIN departments d 
  ON s.dept_id = d.dept_id 
ORDER BY s.gpa DESC;
Key Observation from Actual Data: Notice that Civil Engineering (dept_id = 5) is completely absent from this INNER JOIN result! Why? Because currently 0 enrolled students belong to Civil Engineering. Since there is no matching record in students with dept_id = 5, the INNER JOIN discards it.
