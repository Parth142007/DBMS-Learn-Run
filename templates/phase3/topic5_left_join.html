5. LEFT JOIN — Preserving All Left-Side Records

Discover how Left Outer Joins guarantee that every row from the left table is retained in the output, padding non-matching right-side columns with NULL values to reveal missing relationships.

5.1

How Does a LEFT JOIN Operate?

A LEFT JOIN (also known as LEFT OUTER JOIN) returns all records from the left table, along with the matched records from the right table.

The Left Join Rule: If a row in the left table finds no matching record in the right table, the left-side columns are still returned, while all columns from the right table are populated with NULL.
Diagram 5.1: LEFT OUTER JOIN Set Representation

Figure 5.1: The entire left table (green) is preserved in the output. When right-side records are missing, NULL is substituted.

Syntax
SELECT s.roll_no, r.event_id 
FROM students s
LEFT JOIN registrations r
  ON s.student_id = r.student_id;
Understanding NULL vs 0 vs ""

NULL denotes the absence of any data value (an unmatched record). It is not the number zero (which is an actual numerical quantity), nor is it an empty string (which is a string of length zero).

5.2

Live Verified Example: Identifying Unregistered Students

In our university database, 10 students are enrolled, but students 8 (Ananya), 9 (Arjun), and 10 (Divya) have never registered for any event. A standard INNER JOIN would silently omit them. Watch how LEFT JOIN exposes them:

Run LEFT JOIN: 
SELECT s.roll_no, 
       CONCAT(s.first_name, ' ', s.last_name) AS student_name, 
       r.registration_id, 
       r.event_id, 
       r.status 
FROM students s 
LEFT JOIN registrations r 
  ON s.student_id = r.student_id 
ORDER BY s.student_id ASC;
The Famous "Anti-Join" Pattern (Find Missing Records):

To find only students who have never registered for an event, add WHERE r.registration_id IS NULL. This filters out all matching records, leaving only the unmatched rows! 

SELECT s.roll_no, s.first_name, s.email 
FROM students s 
LEFT JOIN registrations r 
  ON s.student_id = r.student_id 
WHERE r.registration_id IS NULL; -- Returns Ananya, Arjun, Divya!
