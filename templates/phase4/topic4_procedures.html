4.1

What is a Stored Procedure?

A stored procedure is a set of precompiled SQL statements and procedural control logic (such as variable declarations, conditionals, and loops) stored directly inside the MySQL database catalog and executed using the CALL statement.

Stored Procedure vs User-Defined Function (UDF)
Criterion Stored Procedure (CALL) Stored Function (RETURN)
Invocation Invoked via CALL proc_name(args); Called inline inside expressions: SELECT func(col) FROM t;
Return Value Can return 0, 1, or multiple result sets, plus multiple OUT parameters. Must return exactly one scalar value via the RETURN keyword.
Usage in SQL Queries Cannot be used in SELECT, WHERE, or HAVING clauses. Can be embedded anywhere a column expression is permitted.
DML Execution Fully permits INSERT, UPDATE, DELETE, and DDL operations. Strict limitations on mutating table states in standard queries.
1. Reduced Network Traffic

Instead of sending 20 separate SQL queries over the network, the client sends a single CALL sp(...) string. Processing occurs locally inside the database server.

2. Security Encapsulation

Users can be granted EXECUTE permissions on a procedure without granting direct SELECT or UPDATE access to underlying sensitive tables.

3. Precompiled Execution Plan

MySQL parses and optimizes the procedure once, caching execution structures in memory for faster repeated invocations.

4.2

Procedure Syntax & Parameter Modes

Parameter Modes: IN, OUT, and INOUT
IN (Default)
Input Only

Passes a value from caller into the procedure. The procedure can inspect the value but changes inside do not affect the caller's variable.

OUT
Output Only

Initial value is NULL upon entering. The procedure writes results into it, which are returned back to caller's session variable.

INOUT
Bidirectional

Passes an initial value into the procedure, allows the procedure to modify it, and returns the modified result back to caller.

Anatomy of CREATE PROCEDURE
DELIMITER // CREATE PROCEDURE sp_calculate_dept_gpa ( IN in_dept_code VARCHAR(10), OUT out_avg_gpa DECIMAL(3,2), OUT out_student_count INT ) BEGIN -- 1. Declare local variables (must be declared at top of BEGIN block) DECLARE v_dept_id INT; -- 2. Fetch department primary key SELECT dept_id INTO v_dept_id FROM departments WHERE dept_code = in_dept_code; -- 3. Calculate metrics and assign directly to OUT parameters SELECT IFNULL(AVG(gpa), 0.00), COUNT(*) INTO out_avg_gpa, out_student_count FROM students WHERE dept_id = v_dept_id; END // DELIMITER ; -- Calling the procedure with session variables: CALL sp_calculate_dept_gpa('CSE', @avg_gpa, @count); SELECT @avg_gpa AS CSE_Avg_GPA, @count AS Total_Students;
Procedure Inspection & Lifecycle Commands
SHOW PROCEDURE STATUS WHERE Db = DATABASE(); -- List all procedures in current DB
SHOW CREATE PROCEDURE sp_calculate_dept_gpa; -- View exact source code
DROP PROCEDURE IF EXISTS sp_calculate_dept_gpa; -- Safely delete routine
4.3

Live College Schema Stored Procedures

Our application includes four pre-installed, verified stored procedures in database/08_stored_procedures.sql:

Accepts a department code (e.g. 'CSE') and returns all enrolled students with mentor names via a multi-table JOIN.

CREATE PROCEDURE sp_get_students_by_department(IN in_dept_code VARCHAR(10)) BEGIN SELECT s.student_id, s.roll_no, CONCAT(s.first_name, ' ', s.last_name) AS student_name, s.semester, s.gpa, d.dept_name, IFNULL(CONCAT(m.first_name, ' ', m.last_name), 'No Mentor') AS mentor_name FROM students s INNER JOIN departments d ON s.dept_id = d.dept_id LEFT JOIN students m ON s.mentor_id = m.student_id WHERE d.dept_code = in_dept_code ORDER BY s.roll_no ASC; END;

Returns the complete attendee roster and registration status for a designated event ID.

CREATE PROCEDURE sp_get_event_roster(IN in_event_id INT) BEGIN SELECT e.event_name, e.event_date, s.roll_no, CONCAT(s.first_name, ' ', s.last_name) AS attendee_name, r.registration_date, r.attendance_status FROM registrations r INNER JOIN events e ON r.event_id = e.event_id INNER JOIN students s ON r.student_id = s.student_id WHERE r.event_id = in_event_id ORDER BY r.registration_date ASC; END;

Encapsulates business rules: checks if student already registered, checks event capacity, and performs safe atomic registration.

CREATE PROCEDURE sp_register_student_safe( IN in_student_id INT, IN in_event_id INT, OUT out_status VARCHAR(20), OUT out_message VARCHAR(150) ) BEGIN DECLARE v_exists INT; DECLARE v_curr_count INT; DECLARE v_max_cap INT; SELECT COUNT(*) INTO v_exists FROM registrations WHERE student_id = in_student_id AND event_id = in_event_id; IF v_exists > 0 THEN SET out_status = 'REJECTED'; SET out_message = 'Student is already registered for this event.'; ELSE SELECT COUNT(*) INTO v_curr_count FROM registrations WHERE event_id = in_event_id; SELECT max_capacity INTO v_max_cap FROM events WHERE event_id = in_event_id; IF v_curr_count >= v_max_cap THEN SET out_status = 'REJECTED'; SET out_message = 'Event capacity reached.'; ELSE INSERT INTO registrations (student_id, event_id, registration_date, attendance_status) VALUES (in_student_id, in_event_id, CURDATE(), 'Registered'); SET out_status = 'SUCCESS'; SET out_message = 'Registration successfully completed.'; END IF; END IF; END;

Practice Exercises

Exercise 4.1 (Beginner) IN Parameter Procedure

Students by Minimum GPA:

Write a stored procedure named sp_filter_by_min_gpa that accepts IN min_gpa DECIMAL(3,2) and returns all students who have gpa >= min_gpa ordered by GPA descending.

Hint:
CREATE PROCEDURE sp_filter_by_min_gpa(IN min_gpa DECIMAL(3,2)) BEGIN SELECT student_id, roll_no, first_name, gpa FROM students WHERE gpa >= min_gpa ORDER BY gpa DESC; END;
Exercise 4.2 (Advanced) OUT Parameter & Logic

Count Registrations Procedure with OUT Parameter:

Write a procedure named sp_count_student_events that accepts IN p_student_id INT and assigns the total number of events the student registered for into an OUT p_total INT parameter.

Hint:
CREATE PROCEDURE sp_count_student_events(IN p_student_id INT, OUT p_total INT) BEGIN SELECT COUNT(*) INTO p_total FROM registrations WHERE student_id = p_student_id; END;
