Phase 5 — Database Design & Normalization

Eliminate Redundancy, Master Functional Dependencies & Armstrong's Axioms, Decompose 1NF → 2NF → 3NF → BCNF, and Guarantee Lossless Joins

Main Dashboard Phase 4: Views & Security Schema Inspector
Module Learning Objectives

By completing this interactive normalization and schema design module, students will be able to:

Identify Insertion, Update, and Deletion Anomalies caused by uncontrolled data redundancy.
Formulate Functional Dependencies ($X \to Y$), deduce candidate keys, and apply Armstrong's Axioms.
Decompose relations sequentially into 1NF, 2NF, 3NF, and BCNF without losing information.
Differentiate between 3NF and BCNF using prime attributes and superkey determinants.
Test and verify Lossless Join Decomposition and Dependency Preservation in interactive labs.
