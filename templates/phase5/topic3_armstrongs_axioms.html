3. Armstrong's Axioms & Inference Rules

Explore the sound and complete inference rules of relational database theory formulated by William W. Armstrong in 1974 — master the 3 primary axioms (Reflexivity, Augmentation, Transitivity) and the 3 secondary rules (Union, Decomposition, Pseudotransitivity).

3.1

The Three Primary Armstrong Axioms

Armstrong's axioms are sound (they generate only valid functional dependencies that logically follow from $F$) and complete (repeated application will generate the entire closure $F^+$ of all valid dependencies).

Axiom 1: Reflexivity Rule
If Y ⊆ X, then X → Y

Plain English: Any set of attributes functionally determines any of its own subsets.

Database Example: (StudentID, RollNo) → StudentID. If you know both the StudentID and RollNo, you obviously know the StudentID!

Axiom 2: Augmentation Rule
If X → Y, then XZ → YZ

Plain English: Adding the same arbitrary attributes $Z$ to both sides preserves the validity of the dependency.

Database Example: If StudentID → StudentName, then (StudentID, Semester) → (StudentName, Semester).

Axiom 3: Transitivity Rule
If X → Y & Y → Z, then X → Z

Plain English: If $X$ determines $Y$ and $Y$ determines $Z$, then $X$ determines $Z$ directly through the middle term $Y$.

Database Example: If StudentID → DeptID and DeptID → DeptBudget, then StudentID → DeptBudget!

3.2

The Three Commonly Derived Inference Rules

From the three fundamental axioms above, three extremely convenient shortcut rules can be mathematically proven:

Rule 4: Union (Additive)
If X → Y & X → Z, then X → YZ

Plain English: If an attribute determines two separate attributes individually, it determines them collectively.

Example: If RollNo → FirstName and RollNo → LastName, then RollNo → (FirstName, LastName).

Rule 5: Decomposition (Projective)
If X → YZ, then X → Y & X → Z

Plain English: You can break apart attributes on the right-hand side (RHS). Warning: You can NEVER break apart attributes on the left-hand side (LHS)!

Example: RollNo → (GPA, City) implies RollNo → GPA and RollNo → City.

Rule 6: Pseudotransitivity
If X → Y & WY → Z, then WX → Z

Plain English: You can substitute $X$ in place of $Y$ on the LHS of another dependency, preserving any extra attributes $W$.

Example: If StudentID → RollNo and (RollNo, Semester) → Grade, then (StudentID, Semester) → Grade.

Practice Exercises

Exercise 3.1 Proof by Armstrong's Axioms

Prove the Union Rule:

Using only the 3 primary axioms (Reflexivity, Augmentation, Transitivity), prove that if $X \to Y$ and $X \to Z$, then $X \to YZ$.

Proof Steps:
1. Given: $X \to Y$. Augment with $X \implies XX \to XY$, which simplifies to $X \to XY$.
2. Given: $X \to Z$. Augment with $Y \implies XY \to YZ$.
3. Apply Transitivity to $X \to XY$ and $XY \to YZ \implies X \to YZ$. (Q.E.D.)
Exercise 3.2 Common Mistake Warning

Why LHS Decomposition is Strictly Invalid:

A student claims: "If $(A, B) \to C$, then by decomposition $A \to C$ and $B \to C$". Give a concrete counterexample demonstrating why this statement is false.

Counterexample: In an enrollment table, (StudentID, CourseID) → Grade. Neither StudentID → Grade nor CourseID → Grade holds alone, because a student takes multiple courses with different grades! Decomposition applies strictly to the RHS, NEVER the LHS!
