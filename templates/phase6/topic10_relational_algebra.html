1. Relational Algebra: Procedural Query Language

Relational Algebra is a formal procedural query language consisting of operations that take one or two relations as input and produce a new relation as output. It forms the mathematical foundation upon which modern RDBMS query optimizers (including MySQL 8) rewrite, optimize, and execute SQL statements.

Operator Notation Formal Definition & Semantics SQL Conceptual Equivalent
Selection σc(R) Filters rows satisfying predicate condition $c$. Horizontal filtering; does not alter degree. SELECT * FROM R WHERE condition
Projection πL(R) Selects specific columns in list $L$. Eliminates duplicate tuples to enforce mathematical set semantics. SELECT DISTINCT col1, col2 FROM R
Union R ∪ S Combines tuples from two Union-Compatible relations (same degree and compatible domains). Eliminates duplicates. SELECT * FROM R UNION SELECT * FROM S
Set Difference R − S Finds tuples belonging to $R$ that do not appear in $S$. Requires union compatibility. SELECT * FROM R EXCEPT SELECT * FROM S
Cartesian Product R × S Pairs every tuple of $R$ with every tuple of $S$. Degree = $deg(R) + deg(S)$; Cardinality = $|R| \times |S|$. SELECT * FROM R CROSS JOIN S
Rename ρS(A)(R) Renames relation $R$ to $S$, or renames its constituent attributes. SELECT col AS new_col FROM R AS S
Natural Join R ⨝ S Equates shared attributes, pairs matching tuples, and projects only one copy of common attributes. SELECT * FROM R NATURAL JOIN S
Relational Division R ÷ S Finds attributes in $R$ associated with all tuples in $S$. Solves universal quantification queries ("for all"). Nested NOT EXISTS or HAVING COUNT(*) = (SELECT COUNT(*))
Fundamental vs. Derived Operators:
Codd proved that the 5 fundamental operators are $\sigma, \pi, \cup, -, \times$ (plus $\rho$). All other operations are derived:
  • Set Intersection: $R \cap S = R - (R - S)$.
  • Theta / Equi-Join: $R \bowtie_c S = \sigma_c(R \times S)$.
  • Natural Join: $\pi_{unique\_cols}(\sigma_{R.A = S.A}(R \times S))$.

    Test your mastery of relational algebra operators, selection, projection, joins, division, and diagramming.

    1. In classical Relational Algebra, what happens to duplicate rows during a Projection (π) operation?

    2. What condition MUST be satisfied for two relations R1 and R2 to be 'Union-Compatible'?

    3. If relation R has 4 tuples and relation S has 5 tuples, what is the Cardinality of their Cartesian Product (R × S)?

    4. Which real-world query scenario is naturally solved using the Relational Division (÷) operator?
