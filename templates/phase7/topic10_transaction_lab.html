Interactive Learning Sandbox
Welcome to the Safe Educational Transaction Studio

This interactive laboratory provides a completely isolated sandbox to experiment with transaction interleaving, conflict serializability, 2PL lock acquisition, deadlocks, and Write-Ahead Logging (WAL) recovery. All simulations execute safely in memory without altering the application's production tables.

Schedule & Precedence Graph Analyzer

Construct custom schedules using operation buttons or type tokens directly. The backend and client-side graph algorithms parse the sequence, detect conflicting pairs, build the serialization graph, and verify conflict serializability.

Quick Insert Tokens:
Schedule:
Result: CONFLICT-SERIALIZABLE
Order: T1 → T2
[Algorithmic Result] Precedence graph is acyclic. Conflict-equivalent to serial execution T1 -> T2.
Two-Phase Locking (2PL) Protocol Simulator

Verify lock compatibility, observe blocking when incompatible locks are requested, and enforce 2PL growing and shrinking phase rules.

[Lock Engine] Initialized in-memory lock table.
Deadlock & Wait-For Graph Sandbox

Observe mutual dependencies, cycle detection in the Wait-For Graph, and simulate victim selection and rollback.

Write-Ahead Logging (WAL) Recovery Engine

Simulate crash recovery by setting a crash point LSN. The engine calculates the REDO list (committed transactions) and UNDO list (uncommitted active transactions) to restore data consistency.

[WAL Engine] Crash point set at LSN 8. T1 in REDO list. T2 and T3 in UNDO list.

1. Consider the schedule: `R1(X), W2(X), W1(X), C1, C2`. Why is this schedule NOT conflict-serializable?

2. In Strict Two-Phase Locking (Strict 2PL), when are Exclusive (X) locks released?

3. What is the fundamental purpose of the Write-Ahead Logging (WAL) principle during crash recovery?

4. Which SQL isolation level prevents both Dirty Reads and Non-Repeatable Reads, and is the default setting in MySQL InnoDB?

5. If an interleaved schedule of transactions T1, T2, and T3 produces a precedence graph with directed edges T1 → T2 and T2 → T3, what is its equivalent serial execution order?
