SQL Isolation Levels & MySQL 8 InnoDB Implementation

NEPC42 Core Concept
1. The Four Standard ANSI/ISO SQL Isolation Levels

Total strict serializability requires high locking overhead and reduces concurrency. To allow developers to balance data consistency against transaction throughput, the SQL-92 standard formalized four distinct Transaction Isolation Levels. Each level specifies which concurrency anomalies are permitted or prohibited:

ANSI/ISO SQL-92 Isolation Phenomenon Matrix
Isolation Level Dirty Read Non-Repeatable Read Phantom Read Concurrency Performance
Read Uncommitted Allowed Allowed Allowed Highest Throughput
Read Committed Prevented Allowed Allowed High Throughput
Repeatable Read Prevented Prevented Standard: Allowed (InnoDB: Prevented!) Moderate Throughput
Serializable Prevented Prevented Prevented Lowest Throughput
2. SQL Standard Theory vs. MySQL 8 InnoDB Reality

Many textbooks assume that all database systems behave identically to the 1992 standard. In modern production databases like MySQL 8 with the InnoDB engine, there are crucial implementation differences:

MySQL Default
Repeatable Read is the Default

Unlike PostgreSQL and Oracle (which default to Read Committed), MySQL InnoDB defaults to Repeatable Read.

MVCC Architecture
Multi-Version Concurrency Control

Consistent non-locking reads (ordinary SELECT) do NOT acquire shared locks! Instead, InnoDB constructs a Read View and reads prior versions of rows from the Undo Log.

How InnoDB Prevents Phantom Reads in Repeatable Read: While the ANSI SQL standard allows Phantom Reads under Repeatable Read, MySQL InnoDB prevents phantom reads!
  • For Consistent Non-Locking Reads: MVCC Read View creates an immutable snapshot of all committed transactions at the exact moment the first query in the transaction executes.
  • For Locking Reads (FOR UPDATE / FOR SHARE): InnoDB uses Next-Key Locking (a combination of an index record lock and a gap lock on the gap preceding the index record), preventing concurrent sessions from inserting new phantom rows into the range!
